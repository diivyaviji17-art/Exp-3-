# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To analyze and design a Railway Management System by preparing the Software Requirements Specification (SRS) and modeling the system using UML diagrams.
# SRS (Procedure):
1.Study the requirements of the Railway Management System.

2.Identify the users such as Passenger and Administrator.

3.Analyze the functions like train search, ticket booking, ticket cancellation, and schedule management.

4.Define the functional and non-functional requirements.

5.Prepare the Software Requirements Specification (SRS) document.

6.Design the UML diagrams (Use Case, Class, Activity, Sequence, State Chart, and Collaboration diagrams).

7.Verify the requirements and diagrams for correctness.

8.Document the final Railway Management System design.
